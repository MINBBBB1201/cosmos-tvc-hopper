## 개략 합계

| 그룹 | 범위(₩) |
|---|---|
| A 추진·전원 (배터리 3개) | 90–170k |
| B FC·RC (송신기 보유 가정) | 55–110k |
| C 베인·서보 | 25–40k |
| D 구조·필라멘트 | 40–65k |
| E 하드웨어·소모품 | 25–40k |
| F 구속 스탠드 (삼각대 보유 시 ↓) | 40–100k |
| G 안전 | 55–80k |
| **총계** | **≈ 260k – 420k** |

- rev A 총계(₩620k–1.36M) 대비 **약 반값~1/3**.
- 남는 예산 활용: **예비 기체 1대**(프린트+구조+서보 ≈ ₩50k) 또는 배터리·서보 예비 추가 → 크래시 내성·홉 반복.
